AttendWise Download

Know which classes you can skip.

AttendWise is now an Android app. The website version has been retired. The new app is faster, works offline, and adds home-screen widgets and class reminders you can mark from the notification.

Download for Android

What it does

Built for one question: can I miss this class and still stay above the attendance requirement?

Mark today in one tap

Tap or swipe a class to mark it present or absent. The Today list also says which classes are safe to skip.

Safe skips per course

Each course shows its percentage and how many classes you can miss before dropping under the requirement. Zero-tolerance courses like labs are flagged.

Day-off planner

Pick the days you want off. AttendWise tells you which classes are safe to miss, which are risky, and which you must attend.

Institute calendar

Holidays and day swaps are built in. When a Thursday runs Friday's timetable, your class list follows.

Home-screen widgets

Five widgets: can I bunk today, today's classes, your next class, a course's safe skips, and the courses that need attention.

Reminders you can answer

Get a reminder before each class and a prompt after it. Tap Present, Absent or Cancelled right from the notification.

Installing

  1. Open the downloaded .apk file.
  2. If Android asks, allow your browser to install apps.
  3. Sign in with a new account. Data from the old website doesn't carry over, so add your courses again.

Using an iPhone?

There's no iPhone version.
