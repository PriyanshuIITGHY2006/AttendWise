AttendWise is now an Android app

The website version has been retired. The new app is faster, works offline, and adds home-screen widgets and class reminders you can mark from the notification.

Download for Android

Installing

  1. Open the downloaded .apk file.
  2. If Android asks, allow your browser to install apps.
  3. Sign in with a new account. Data from the old website doesn't carry over, so add your courses again.
