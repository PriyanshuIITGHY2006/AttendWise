## On the Today screen

Each class has a tick and a cross. You can also **swipe right for present** and **swipe left for absent**. **Mark all present** marks every class of the day at once.

Tap a class to choose exactly how it counts:

| Choice | Effect |
|---|---|
| Present | Counts as attended. |
| Absent | Counts as missed. If the class is later today or in the future, this is a planned skip until the class starts. |
| Cancelled | Does not count for or against you. |
| On duty | Does not count for or against you. |

To undo, tap the class and choose **Clear mark**.

## From a notification

After a class ends, AttendWise can send a prompt with **Present**, **Absent** and **Cancelled** buttons. You mark the class without opening the app. See [notifications and reminders](/AttendWise/help/notifications-and-reminders.html).

## From a widget

The Today widget has Present and Absent buttons for each class. See [widgets](/AttendWise/help/widgets.html).

## From the Calendar

Open the Calendar tab, tap a day, and mark or change any class that day. This is the way to fix past days.

## How marks count

- A mark counts once the class has started. Before that, an absent mark is a plan, not a fact.
- Classes that have ended but are not marked yet are treated as classes you can still attend. This keeps the numbers hopeful but honest, and the app reminds you to mark them. Mark them to get exact numbers.
- Percentages are rounded down, so 74.9 percent never shows as 75 percent.
