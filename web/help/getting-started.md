## Install

Download the latest APK from the [home page](/AttendWise/) and open it. If Android asks, allow your browser to install apps. AttendWise needs Android 8.0 or newer. There is no iPhone version.

## Sign in

Open the app and sign in with **Continue with Google**, or use your name, email and a password of at least 6 characters. Forgot your password? Use **Forgot password?** on the sign-in screen.

## Set up in three steps

The app walks you through setup the first time.

1. **About you.** Enter your name. Turn on **First-year UG** if you follow the first-year-only day swaps.
2. **Your semester.** Give it a name, for example Winter 2027, and set the start and end dates. Add the mid-semester dates too if you have half-semester courses.
3. **Your courses.** Add each course with a code and a name, then its weekly class times. Tap **Finish setup** when you are done.

## Setting up a course

- **Attendance needed.** Choose 75, 80, 85 or 100 percent, or **Custom** for any other number.
- **Never skip.** Turn this on for labs and strict instructors. AttendWise will never show skips for that course.
- **Runs for.** Full semester, first half or second half. Half-semester courses need the mid-semester dates in your semester.
- **Weekly timetable.** Tap **Add class time** for each day and time. Changes apply from today, so your past attendance stays correct.

## The five tabs

| Tab | What it is for |
|---|---|
| Today | The day's classes. Mark them here. |
| Courses | Every course with its percentage and safe skips. |
| Plan | Pick days you want off and see what that would cost. |
| Calendar | The month, with holidays and day swaps. |
| Profile | Settings, notifications, semester, updates and sign out. |
