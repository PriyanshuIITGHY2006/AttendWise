## If you used the old website or old app

The old AttendWise website and the app that wrapped it have been retired. They are replaced by a native Android app, which is faster, works offline and adds widgets and reminders you can answer from the notification.

1. Remove the old app. Press and hold its icon on your home screen and choose **Uninstall** or **Remove**.
2. Download the new app from the [home page](/AttendWise/) and install it.
3. Sign in. Data from the old version does not carry over, so add your courses and timetable again. See [getting started](/AttendWise/help/getting-started.html).

If you open an old version, it shows a notice that it has been retired, with these same steps.

## If you have an early build of the new app

The first two builds of the new app (builds 3 and 4) did not have in-app updates, so they cannot tell you about new versions.

- Download the newest file from the [home page](/AttendWise/) and install it.
- If you had the test build, the signed app installs next to it as a separate app. Sign in with the same account, check your data is there, then uninstall **AttendWise test**.

Your data is kept in your account, so you will not lose what you had synced. From build 7 on, the app updates itself. See [updating the app](/AttendWise/help/updating-the-app.html).
